# Constraint / part-data provenance (opus_tfhe)

## DDR4 pins and part data: generated (since 2026-11-06)

`BCU1525_DIMM0.xdc` .. `BCU1525_DIMM3.xdc` and `BLS4G4D240FSB.csv` are GENERATED by
`synth/scripts/gen_ddr4_constraints.py` (`--check` verifies the files on disk). Inputs:
- `xilinx_vcu1525/part0_pins.xml`: AMD/Xilinx VCU1525 board file, XilinxBoardStore 2024.2
  `vcu1525/1.3/part0_pins.xml`, Apache-2.0 (licence header kept in the file); byte-identical to
  fable5_llm `evidence/recon/vcu1525_part0_pins.xml` (sha256 830a5500...ff2a).
- the generator's own tables: which board-file byte lane is unpopulated on the BCU-1525's 64-bit
  UDIMMs (c0:7 c1:7 c2:3 c3:2, a board-wiring fact confirmed by DDR4 calibration), and the
  JEDEC JESD79-4 DDR4-2400 4Gb x8 timings for the part CSV (tFAW 21 ns; tRCD/tRP 14.16 ns and
  tRFC 350 ns are conservative).
I/O standards and terminations are left to the DDR4 IP's own generated XDC. These replace the
GPLv2 community files used up to build 029 (github.com/d953i/Custom_Part_Data_Files, via fable5_llm);
the generated files assign the same FPGA package pins on every channel (checked), with a different
DQ bit / byte-lane order and the IP's default I/O settings. Builds up to and including 029 used the
community files; git history before this change still contains them.

## Upstream provenance (as recorded by fable5_llm, `synth/constraints/PROVENANCE.md` @ 35d95a5)

- (historical, builds up to 029) `BCU1525_DIMM[0-3].xdc` and `BLS4G4D240FSB.csv` came from
  github.com/d953i/Custom_Part_Data_Files (GPLv2), community pin data for the SQRL BCU-1525.
- PCIe x8 GT placement cross-checked by fable5_llm against the official Xilinx VCU1525 board files
  (XilinxBoardStore 2024.2, `vcu1525/1.3/preset.xml`: mode Advanced, en_gt_selection=true,
  select_quad=GTY_Quad_227, 8.0 GT/s; refclk AM10/AM11) and a Vivado 2024.2 device-model query.
- Local deviation in fable5_llm (2026-06-11): `BLS4G4D240FSB.csv` tFAW for the -2400 grade corrected
  13000 ps -> 21000 ps (4Gb x8 components, 1 KB page, need 21 ns; found by DDR4 example-design
  simulation with the Micron model). The copy here contains that correction.
